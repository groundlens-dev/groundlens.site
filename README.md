# groundlens.dev

Marketing website for [groundlens](https://github.com/groundlens-dev/groundlens) — geometric LLM hallucination detection.

Built with [Astro](https://astro.build) + [Spectre](https://github.com/LukeHagar/spectre) theme.

## Development

```bash
pnpm install
pnpm dev
```

## Deployment

The site deploys automatically via GitHub Actions to Cloudflare Pages on push to `main`.
